# Blog inbox

Drop documents here and Claude turns them into blog entries.

1. **Make a folder for each entry**, e.g. `blog-inbox/user-interviews/`. You can also drop files straight into this folder.
2. **Put your document inside**: a Word file (.docx) or a PDF.
3. **Put every image the document mentions** in the same folder.
4. **Mark where each image goes:** add a box (or a line) containing the image's exact file name in brackets, like `[sketch-01.jpeg]`. For a caption, write it on the line right under the box.
5. **Ask Claude**, e.g. "import blog-inbox/user-interviews into the blog".

Claude keeps your wording, places the images, saves the entry as a draft, and shows you a preview. When you're happy with it, set `draft: false`, then commit and push.

**Google Docs:** File → Download → Microsoft Word (.docx). **Pages:** File → Export To → Word or PDF.

This folder stays on your computer. Only the finished entry and its images go to GitHub.
